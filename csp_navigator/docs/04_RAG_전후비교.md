## 3. 질문별 평가

### Q1. 지방자치단체 민원 시스템을 클라우드로 옮기려 한다. 공공 요건을 충족하는 CSP는 어디인가?

| 기준 | RAG 없이 | RAG 사용 |
|---|---|---|
| 사실 정확성 | ✕ CSAP를 "행정안전부 클라우드 보안인증"이라고 함(실제 근거 고시는 과학기술정보통신부고시, 인증기관은 KISA). 대상 밖인 MS Azure를 후보로 듦 | ○ NCP 2022-02-24~2027-02-23, NHN 2022-12-13~2027-12-12, KT 2026-03-25~2031-03-24, SCP 2024-08-28~2029-08-27, AWS·GCP 하등급만 보유 — `csap.json`과 모두 일치. 오탈자 1곳("CFAP") |
| 근거 제시 | ✕ 없음 | ○ KISA 발급현황 요약·제도 변경 요약을 번호로 인용 |
| 모름 인정 | ✕ 확인 안 된 내용("일부는 공공기관 특화 보안 인증을 획득")을 단정 | △ 상세 제원은 "확인 필요"라고 했지만 그 문장에 무관한 근거 번호를 붙임(→ 4장 조치 ②) |

### Q2. 인터넷과 완전히 분리된 사내망에서만 접근하는 ERP를 구성하려면 어떤 상품이 필요한가?

| 기준 | RAG 없이 | RAG 사용 |
|---|---|---|
| 사실 정확성 | ✕ "퍼블릭 클라우드는 인터넷 연결 필수라 적합하지 않다"고 단정 — 수집 자료상 전용회선·사설 연결 상품이 CSP마다 있음(폐쇄망 '지원' 확인 14건) | ○ KT Connect Hub 1Gbps(Shared) 140,000원/월, Seoul M1 존 — 상품 메타 KT-NET-02와 일치 |
| 근거 제시 | ✕ 없음 | ○ 상품 메타데이터 인용 |
| 모름 인정 | ✕ | ○ 다른 CSP의 폐쇄망 보장 여부는 "문서에서 확인되지 않음". 단, 같은 색인에 AWS Direct Connect(AWS-NET-03)가 있는데 검색되지 않은 점은 검색 범위의 한계(선택 상품 중심 질의응답) |

### Q3. 월 예산 5만 원 안에서 학습용 웹 서버 + DB를 띄울 수 있는 가장 저렴한 조합은?

| 기준 | RAG 없이 | RAG 사용 |
|---|---|---|
| 사실 정확성 | ✕ "AWS RDS 프리티어 12개월 무료"라고 함 — 수집 자료(계정 단위 무료 혜택 요약)는 AWS가 신규 계정에 최대 200 USD 크레딧·최대 6개월 무료 플랜을 준다고 기록. NCP VM·MySQL 금액은 출처 없는 추정 | △ NCP Server Micro-g1(Classic) 월 13,000원·1년 무료는 일치하나 무료 조건(계정당 1대, 한국 거주자)을 빠뜨림. DB 쪽은 DynamoDB 예시 금액만 들고 최저 조합을 끝내 제시하지 못함 |
| 근거 제시 | ✕ 없음 | ○ 상품 메타·AWS 공식 문서 인용 |
| 모름 인정 | ✕ | ○ "NCP DB 요금과 무료 티어는 문서에서 확인되지 않음" |

참고: 이 질문은 여러 CSP를 견주는 질문이라 상품 1개 중심의 질의응답보다 **CSP 추천·설계 화면(F2010)** 이 맞다. 같은 조건(학습용, 1대 1vCPU/1GB + MySQL, 예산 5만 원)으로 추천 화면을 실행하면 코드 계산으로 **AWS 월 41,531원**(오브젝트 스토리지 0GB) / **44,866원**(100GB 포함, 화면 캡처 `13_rec_learning_*.png`)을 근거 번호와 함께 낸다.

### Q4. 서울 리전에서 2vCPU·8GB 서버를 월 730시간 쓰면 CSP별 비용 차이는?

| 기준 | RAG 없이 | RAG 사용 |
|---|---|---|
| 사실 정확성 | ✕ CSP별 금액을 "월 6~9만 원대" 같은 범위로 추정. 대상 밖 Azure 포함 | △ NCP 119원/시간, 730시간 환산 86,870원은 상품 메타와 일치(공식 월 요금 85,120원은 언급 안 함). GCP는 서울 단가를 찾지 못했고 나머지 4개 CSP는 비교하지 못함 |
| 근거 제시 | ✕ 없음 | ○ 상품 메타·GCP 공식 문서 인용 |
| 모름 인정 | ✕ | ○ "서울 리전 가격은 문서에 없음", "타 CSP 정보는 제공되지 않아 비교 불가" |

참고: CSP 6곳 비교는 추천 화면이 서버 가격표 1,708행으로 코드 계산한다(`15_rec_private_compare.png` 등 후보 비교 탭).

### Q5. 공공기관이 외부 SaaS가 아닌 IaaS로 구성할 때 데이터 저장 위치 요건은?

| 기준 | RAG 없이 | RAG 사용 |
|---|---|---|
| 사실 정확성 | ✕ "국가보안기술연구소 검증(PIMS, GDPR 대응 등)" 같은 근거 없는 제도를 사실처럼 나열 | △ SCP 상품의 공공 요건 '확인 필요'와 한국 리전 제공은 일치. 다만 "국내 리전에 물리적으로 저장되어야 하는 등" 일반론 한 문장은 인용 근거 없이 씀 |
| 근거 제시 | ✕ 없음 | △ 근거를 달았지만 저장 위치와 관계없는 AWS 요금 문서 4개를 인용 |
| 모름 인정 | ✕ | ○ "공공기관 데이터 저장 위치 요건과 직접 관련된 정보는 문서에서 확인되지 않음" |

## 4. 결론과 조치

1. **RAG 없이** 답하면 5개 질문 모두 출처를 확인할 수 없고, 3개 질문(Q1·Q2·Q5)에서 틀린 사실이나 없는 제도를 단정했다. 비용·인증처럼 시점에 따라 바뀌는 정보에서 위험이 크다는 요구사항 정의서 3.3의 가정이 실제로 확인됐다.
2. **RAG 사용** 답변은 숫자·인증 기간이 모두 수집 자료와 일치했고, 자료에 없는 것은 "확인되지 않음"으로 답했다. 남은 약점은 (a) 상품 1개 중심 질의응답이라 여러 CSP를 견주는 질문(Q3·Q4)에 답이 불완전한 점, (b) '확인되지 않음' 문장에 무관한 근거 번호를 붙이는 점이다.
3. 조치
   - ① 비교형 질문은 CSP 추천·설계 화면(F2010)으로 안내한다. 이 화면은 비용을 코드로 계산해 6개 CSP를 모두 비교한다.
   - ② 이 비교를 실행할 때 프롬프트3에는 이미 "'문서에서 확인되지 않음' 문장에는 근거 번호를 붙이지 않는다"는 규칙이 있었지만 LLM이 지키지 않았다. 그래서 코드(`citations.drop_on_not_found`)가 그런 줄의 근거 번호를 지우도록 보강했다(2026-10-23, 설계문서 9장 #15). 이 비교는 코드 보강 전에 실행한 결과다.
   - ③ 공공 요건 질문(Q5)을 보강하려고 「클라우드컴퓨팅서비스 보안인증에 관한 고시」 PDF를 색인했다(F2016). 수정 후 공공 질문에서 PDF 근거가 쪽 번호와 함께 인용되는 것을 확인했다(`07b_public_pdf_evidence.png`).
