## 5. 수집기 동작 (NF2006)

- 웹 페이지는 robots.txt를 먼저 확인하고, 불허·확인 불가면 가져오지 않는다.
- 같은 호스트 호출 간격 1초, 429·5xx·연결 오류는 1.5초 × 2ⁿ 백오프(최대 4회), `Retry-After` 준수.
- 이미 수집한 검색어·문서는 캐시(`data/cache/`)에서 다시 쓴다.
- PDF는 사람이 이용 조건을 확인하고 `data/pdf/catalog.json`에 `use: true`로 등록한 파일만 읽는다. 자동 내려받기는 하지 않는다.
